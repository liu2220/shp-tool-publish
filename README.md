# SHP 工具 · 发布 / 下载页

本仓库是 SHP 工具各交付包（网页版 / UOS 版 / Win7 版 / 手机版 / 义乌影像瓦片）的**发布与下载落地页**源码。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 发布页前端：下载卡片 + 底部可折叠「更新日志 · 重要提示」面板（固定高度内滑动查看，不占主页空间） |
| `app.py` | 下载服务：用无扩展名流式路由返回大文件，绕过 WAF 对 `.zip` / `.tar.gz` 直链的拦截，并强制 `no-store` 防客户端缓存旧包 |
| `pack_release.py` | 各平台交付包打包脚本（含 `uos-source` / `uos-portable` / `win7-portable` 等目标） |
| `img/` | 截图等静态资源 |
| `更新日志.md` | 全版本（v1 → 最新）更新明细 |

## 本地预览

```bash
cd downloads
PORT=3000 python3 app.py
# 浏览器打开 http://localhost:3000
```

## 发布页日志面板说明

更新日志原本整段堆在主页底部、占空间且不利于查看，现已改造为：

- **独立折叠面板**，置于页面最底部；
- **固定高度（360px）内部滚动**的滑动窗口，长日志不再撑开整页；
- 点击标题栏「📋 更新日志 · 重要提示」即可展开 / 收起。
